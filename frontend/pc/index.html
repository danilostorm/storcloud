Para jogos Windows/Linux que não possuem port WebAssembly, o Local Agent inicia o executável permitido no computador do jogador. CPU, GPU, DirectX/Vulkan e áudio continuam locais — sem transformar a VM StorCloud em uma máquina de renderização.

arquitetura local-first

Decisão automática

O StorCloud prioriza Browser WASM/WebGPU. Quando isso não for possível, usa o Local Agent. Streaming remoto fica como último fallback.

WASM disponível → navegador\nAgente compatível → PC local\nSem rota local → streaming fallback
alpha

Segurança

O agente não aceita comandos de shell nem caminhos enviados pelo site. Ele só lança IDs presentes numa lista local permitida e protegida por token.

Se o agente aparecer offline mesmo estando aberto, configure STORCLOUD_ORIGINS com a origem exata do seu StorCloud, por exemplo http://192.168.30.8:8080.
